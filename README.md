# 2026-DHIS2-asia-pacific-conference

## Opening in localhost

### 1. Open folder containing the website in Visual Studio Code

### 2. Open Terminal in the Visual Studio Code
... > Terminal > New terminal

### 3. Select Command Prompt from the menu next to + sign (click on \/ sign)

### 4. Check npm
npm --version

### 5. Install the website dependencies
npm install

### 6. Start the website
npm run dev

### 7. Open the website
http://localhost:3000
